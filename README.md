1. 가입 페이지에서 국가가 대한민국으로 되어 있는지 확인하고 약관에 동의합니다.
2. 사용할 이메일을 입력하고, 아래 초대코드 칸이 채워져 있는지 확인합니다.
3. 메일로 온 인증 코드를 넣고 휴대폰 번호 등록과 문자 인증을 진행합니다.

5. OKX 앱을 설치하고 로그인한 뒤 신원 인증을 시작합니다. 신분증 종류를 고르고 앞면과 뒷면을 촬영하고, 이어서 실시간 얼굴 인증을 합니다. 촬영한 신분증을 기준으로 인적 사항이 자동 입력되면 도로명 주소와 우편번호를 넣습니다. 영상에서 안내한 기준으로는 보통 10~30분 안에 완료됩니다.
6. 내 정보 → 보안에서 Google OTP를 설정합니다. 휴대폰과 이메일 인증을 한 번 더 거친 뒤 QR 코드를 OTP 앱으로 스캔하고, 앱에 뜬 6자리 숫자를 OKX에 입력하면 끝납니다.

9. 업비트에서 USDT 출금을 누르고 **네트워크를 OKX와 똑같이 TRON으로 선택**합니다. 수량을 입력하고, 받는 곳은 OKX, 받는 주소에는 복사한 주소를 붙여넣습니다.

거래소 초대코드는 계정에 붙고 할인율이 20%로 고정입니다. 지갑 추천 코드는 기기에 붙고 할인율이 코드마다 다릅니다. 검색으로 나온 코드가 어느 쪽인지 헷갈린다면, 그 코드를 안내하는 페이지에 거래소 가입 화면이 있는지부터 보면 구분됩니다.

## 20% 외에 받을 수 있는 것

가입 페이지에는 신규 사용자를 위한 3일짜리 단기 상품 안내가 있습니다. 첫 거래 전에 신원 인증을 마친 사용자가 한 번만 신청할 수 있는 형태이고, 3일이 지나면 일반 상품으로 자동 전환됩니다. 최고 연 30%라고 적혀 있어도 실제 금액은 크지 않습니다. 1,000 USDT를 3일 넣어도 2.5 USDT 정도 차이입니다. 참여 가능 여부와 한도는 앱에 표시되는 내용이 기준입니다.

초대코드로 가입하면 신규 사용자 보상 프로그램에 자동으로 들어갑니다. 다만 세부 조건은 지역과 시기에 따라 바뀌므로 앱에서 확인해야 합니다. 예전에 돌던 "2만 USDT 복권" 같은 이야기는 지금 초대 페이지나 공식 규칙 어디에도 없습니다. 그런 문구를 보고 가입을 결정한다면 기대를 접는 게 좋습니다.

따로 운영되는 공식 초대 이벤트도 있습니다. 친구가 지정된 코드를 직접 입력해 가입하고 신원 인증을 마친 뒤 거래하면, 가입 후 30일 동안 발생한 수수료를 기준으로 2~200 USDT와 한정 굿즈를 지급하는 방식입니다. 30일이 지난 뒤의 수수료는 집계되지 않고, 상금 풀이 소진되면 조기 종료됩니다. 최고 단계를 받으려면 30일 안에 수수료를 2,000 USDT 이상 내야 합니다. 이 이벤트는 피초대자의 20% 할인과는 별개 제도라서, 코드를 넣었다고 자동으로 돈이 들어오는 건 아닙니다.

모든 거래에 환급이 붙지는 않습니다. 등급이 VIP 7 이상이거나, 특수 요율이 적용된 거래, 수수료 쿠폰을 쓴 거래는 환급 대상에서 빠집니다. 또 OKX는 OKB로 수수료를 깎아주지 않습니다. 공식 FAQ에 현재 OKB 수수료 차감을 지원하지 않는다고 적혀 있습니다. 다른 거래소에서 플랫폼 코인으로 추가 할인을 받던 습관이 있다면 여기서는 해당되지 않습니다.

수수료를 실제로 낮추는 방법은 세 가지로 정리됩니다. 가입할 때 초대코드로 20%를 받고, 급하지 않은 주문은 시장가 대신 지정가로 내고(0.08%가 0.1%보다 낮습니다), 거래량이 충분히 크다면 VIP 등급을 노리는 것입니다. 세 번째는 월 거래액이 100만 달러를 넘어야 시작되는 이야기라, 대부분에게는 앞의 두 가지가 전부입니다.
